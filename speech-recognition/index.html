인공지능 기초 · Ⅱ-2 딥러닝

인공지능은 내 말을
어떻게 알아들을까?

사람에게는 쉬운 '듣기'가 인공지능에게는 아주 어려운 일이에요. 말소리를 떨림(주파수)으로 나누어 보고, 가장 작은 소리 단위(음소)를 찾아, 가장 그럴듯한 문장으로 바꾸는 음성 인식을 배워 봅니다.

오늘 우리는

사람의 말소리가 어떤 모양의 떨림인지 눈으로 확인하고, 그 떨림에서 음소를 찾아 텍스트로 바꾸는 음성 인식의 원리를 배웁니다. 규칙을 하나하나 정해 주던 옛 방식과 많은 목소리를 학습한 딥러닝 방식을 비교하고, 마지막에는 내 발음을 확인해 주는 프로그램을 직접 만들어 봅니다.

왜 배울까
  • AI 스피커도 휴대폰 음성 비서도 먼저 내 말을 글자로 바꿔야 대답할 수 있어요. 음성 인식은 말로 기기를 쓰는 모든 서비스의 첫 단계예요.
  • 운전·요리처럼 손을 쓰기 어려울 때, 또 손이나 눈이 불편한 사람도 말만으로 기기를 쓸 수 있게 해 줘요.
  • 지난 시간 '보는' 인공지능(컴퓨터 비전)에 쓰인 딥러닝이 '듣는' 인공지능에서는 어떻게 쓰이는지 이어서 알 수 있어요.
어디에 쓰일까
  • 기기 제어 · "불 꺼 줘" 한마디로 조명과 커튼을 움직이는 스마트 홈
  • 텍스트 기록 · 회의 내용을 받아 적는 자동 회의록, 진료 내용을 기록하는 병원 시스템
  • 외국어 교육 · 내 발음을 듣고 맞았는지 알려 주는 어학 앱
  • 자막 생성 · 영상에 자동으로 붙는 자막, 수업 내용을 실시간 글자로 보여 주는 서비스
배우고 나면 할 수 있는 것
  • 주파수가 무엇인지 말하고, 높은 소리와 낮은 소리를 주파수로 구분한다.
  • 낱말을 음소로 나누고, 글자와 실제 소리가 다른 예를 찾는다.
  • if-then 방식과 딥러닝 방식의 음성 인식을 비교해 설명한다.
  • 음성 인식이 앞뒤 말(맥락)을 보고 텍스트를 고른다는 것을 체험으로 확인한다.
  • 음성 인식의 활용 분야를 실생활 예와 짝짓는다.
  • 음성 인식 결과와 원래 문장을 비교하는 발음 연습 프로그램을 설계하고 실행한다.

교과서 110쪽 · 그림 Ⅱ-30 if-then 방식과 딥러닝 방식

① 규칙 방식이 약했던 까닭: 사람마다 다른 목소리

초기 음성 인식은 음소를 낱말로 만드는 규칙을 if-then으로 하나하나 정해 두었어요. 그런데 같은 음소도 사람마다 높낮이·크기·빠르기가 달라요. 말하는 사람을 바꿔 보세요.

저장된 주파수 정보와 닮은 정도
if-then 방식 결과
딥러닝 방식 결과

딥러닝 모델은 대량의 음성 데이터로 학습해서, 목소리가 달라도 같은 음소를 알아들어요. 그래서 정확도가 크게 높아졌어요.

※ 두 방식의 차이를 보여 주려고 만든 예시 결과예요.

② 딥러닝은 확률이 높은 문장을 골라요

딥러닝 방식은 들린 소리로 만들 수 있는 여러 문장 가운데 가장 그럴듯한(확률이 높은) 문장을 골라요. 인공지능이라면 무엇을 고를지 먼저 눌러 보세요.

※ 확률은 원리를 보여 주려고 정한 예시 숫자예요.

글자가 바뀐 기록

말하는 동안 인공지능이 적은 글자를 순서대로 모았어요. 노란 줄은 앞에서 적은 글자를 고친 순간이에요.

  1. 버튼을 누르고 말하면 여기에 차례로 기록돼요.

실험해 보기

왜 말하는 도중에 글자가 바뀔까?

처음에는 앞부분 소리만 듣고 가장 그럴듯한 글자를 적어요. 뒷말이 들어오면 문장 전체를 다시 보고 확률이 더 높은 문장으로 고쳐요.

[가치]만 들었을 때'가치'일까 '같이'일까? 아직은 알 수 없어요. 뒤에 무슨 말이 올지 기다려야 해요.
[가치 가자]까지 들었을 때'가자' 앞에는 '같이'가 훨씬 자연스러워요. 앞뒤 말, 곧 맥락이 단서가 되어 '같이 가자'로 고쳐요.

03에서 본 "확률이 높은 텍스트로 변환"이 지금 눈앞에서 일어난 거예요.

7. 오디오 파일의 음성 인식하기 
# 음성 인식
!pip install speechrecognition  # 음성 인식 모델을 불러올 수 있는 라이브러리 설치
import speech_recognition as sr

r = sr.Recognizer()
sound = sr.AudioFile('play1.wav')
with sound as source:
  audio = r.record(source)
print(r.recognize_google(audio, language = 'ko-KR'))
  • r.record(source) · 파일의 소리를 읽어 audio에 담아요. 입력
  • r.recognize_google(audio, language = 'ko-KR') · 구글의 딥러닝 음성 인식 모델에 보내 한국어 텍스트로 바꿔요. 처리
8. 원래 문장과 비교해 결과 출력하기 
# 음성 인식 결과 비교
text = '내가 그린 기린 그림은 잘 그린 기린 그림이고 네가 그린 기린 그림은 잘 못 그린 기린 그림이다'
s_text = r.recognize_google(audio, language = 'ko-KR')
if text == s_text:
  print('완벽한 발음입니다!')
else:
  print('연습이 필요합니다!')

음성 인식은 사람의 말소리를 분석하여 텍스트 데이터로 바꾸는 것을 말한다.
규칙을 일일이 정한 if-then 방식은 사람마다 다른 발음에 약했지만, 대량의 음성 데이터로 학습한 딥러닝 방식이 정확도를 크게 높였다.
음성 인식은 사물 인터넷이나 자연어 처리 등의 기술과 융합하여 다양한 분야에서 활용되고 있다.
주파수1초 동안 진동하는 수. 빠르게 반복 = 고주파수 = 높은 소리🎵 200 Hz = 1초에 200번 떨림
음소언어의 가장 작은 소리 단위. 글자와 실제 소리는 다를 수 있다🔤 문 = ㅁ + ㅜ + ㄴ, 같이 → [가치]
인식 과정주파수 분석 → 음소 추출 → 텍스트 변환〰️ → ㅁㅜㄴ → 문
if-then 방식저장된 주파수 정보와 규칙대로 변환. 목소리가 다르면 틀리기 쉽다🚪 문이 다칩니다?
딥러닝 방식많은 음성 데이터로 학습. 맥락을 고려해 확률이 높은 텍스트를 고른다🚪 문이 닫힙니다. ✔
