## 만든 방식과 원칙

- 순수 HTML·CSS·자바스크립트 한 파일씩. 빌드 과정 없음, GitHub Pages로 바로 배포
- 개념 설명은 붓꽃(iris) 데이터 하나로 이어 가고, 예시 숫자는 실제 데이터로 계산해 확인한 값만 씀 (예: 편향 0 → −3에서 틀린 꽃 50 → 5 → 0송이)
- 용어와 시험용 계산은 교과서 표기·숫자를 따름 (MSE 41.67, 파라미터 84,060 등)
- 퀴즈 기록은 학생 브라우저에만 저장되고 따로 모이지 않음
- **공개 저장소이므로 정답판·교사용 안내는 올리지 않음** (교사 컴퓨터의 학기 저장소에 보관)
