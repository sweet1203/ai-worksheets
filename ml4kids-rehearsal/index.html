남극 연구소의 부상당한 펭귄
남극 연구소에서 다친 펭귄을 발견했는데 어떤 종인지 알 수 없어요. 종마다 먹이와 치료 방법이 달라 꼭 알아야 하는데, 카메라도 고장 났어요. 부리와 날개 같은 생김새만으로 펭귄의 종을 구별하는 인공지능을 만들 수 있을까요?

교과서 펭귄 프로젝트로 프로젝트 수행 과정을 익히고, 예시 프로젝트 하나로 ML4Kids 수행평가의 전 과정을 미리 연습해요. 오늘 연습은 성적에 들어가지 않아요.

오늘 우리는

교과서 남극 펭귄 프로젝트로 인공지능 프로젝트 수행 과정을 정리하고, 쇼핑 리뷰 긍정·부정 분류라는 예시 프로젝트로 수행평가에서 할 일을 순서대로 한 번 해 봅니다. 특히 틀린 사례 찾기 → 개선 → 같은 테스트로 비교와 Scratch 연결을 꼭 해 봐요.

왜 연습할까
  • 수행평가는 2차시뿐이라 도구 사용법을 그때 처음 배우면 시간이 모자라요.
  • 오늘 막히는 곳을 미리 찾아 두면 수행평가 때는 내 주제에만 집중할 수 있어요.
학습 목표 (178쪽)
  • 인공지능 프로젝트 수행 과정을 설계할 수 있다.
  • 인공지능 프로젝트 수행 과정에 따라 문제를 해결할 수 있다.
배우고 나면 할 수 있는 것
  • 프로젝트 수행 과정과 역할을 설명한다.
  • 테스트 결과를 숫자로 기록하고 틀린 사례의 원인을 데이터에서 찾는다.
  • 모델 결과로 동작하는 Scratch 프로그램의 구조를 안다.

🧭프로젝트 기획자주제를 정하고 일정과 방향을 이끌어요내 문제·계획 정하기

02

ML4Kids 따라 하기

예시 프로젝트: 쇼핑 리뷰 긍정 / 부정 (유형 카드 02)

쉽게 말하면ML4Kids는 훈련 → 학습 & 평가 → 만들기 세 칸으로 되어 있어요. 데이터를 넣고(훈련), 모델을 만들어 시험해 보고(학습 & 평가), Scratch로 프로그램을 만들어요(만들기). 손글씨 숫자 실습 때와 같은 순서예요.
  1. 새 프로젝트 만들기

    학급 계정으로 로그인 → 「프로젝트」 → 「+ 새 프로젝트 추가」 → 이름(예: 리뷰감정)을 쓰고 인식 대상을 텍스트로 골라 「만들기」.

  2. 레이블(클래스) 만들기

    「훈련」 → 오른쪽 위 「+ 새로운 레이블 추가」 → 긍정, 부정 두 개를 만들어요.

  3. 학습 데이터 넣기

    레이블 상자 아래 「데이터 추가」로 아래 문장을 직접 입력해요. 클래스마다 8개씩, 개수를 똑같이 맞춰요.

  4. 테스트 문장은 따로 떼어 두기

    3번 화면의 테스트 문장 4개는 절대 학습 데이터에 넣지 않아요. 넣으면 처음 보는 문장을 맞히는지 알 수 없어요.

  5. 학습시키기

    「학습 & 평가」 칸에서 학습 버튼을 누르고 끝날 때까지 기다려요.

  6. 테스트하기

    같은 화면의 입력 칸에 테스트 문장을 하나씩 넣고, 예측 결과와 신뢰도를 표에 적어요.

      04

      Scratch 연결

      모델의 예측 결과로 실제로 움직이는 프로그램 · 활동지 5번

      쉽게 말하면「만들기」 → Scratch 3을 열면 내 모델 전용 블록이 생겨요. 입력을 모델에 넣어 레이블(예: 긍정)을 받아 오는 블록으로 만약 ~라면을 만들면, 결과에 따라 다르게 움직이는 프로그램이 돼요.

      예시 프로그램: 리뷰를 입력하면 별점 보여 주기

      깃발을 클릭했을 때 「리뷰를 입력하세요」 묻고 기다리기 만약 대답 을 인식한 레이블 = 긍정 이라면 「⭐⭐⭐⭐⭐ 좋은 리뷰네요!」 말하기 아니면 「⚠️ 불만 리뷰예요」 말하기 신뢰도 보기: 대답 을 인식한 신뢰도

      파란 블록이 ML4Kids가 만들어 주는 내 모델 블록이에요. 화면의 블록 이름은 조금 다를 수 있어요.

      ✅ 프로그램 점검

      • ☐ 모델 블록의 결과(레이블)로 분기한다 (모델 없이 정해진 대로만 움직이면 안 돼요)
      • ☐ 모든 클래스에 대해 다른 동작이 있다
      • ☐ 테스트 문장을 넣어 실제로 끝까지 실행된다
      • ☐ 실행 화면을 캡처하거나 링크를 저장했다
      • ☐ (선택) 신뢰도가 낮으면 「잘 모르겠어요」라고 말하게 했다

      채점 기준 요소 ①: 「실행 가능한 산출물」이 없거나 실행되지 않으면 40점을 받을 수 없어요.

      06

      마무리

      핵심 문장 · 수행평가 준비물 · 마무리 퀴즈 · 질문폼

      인공지능 프로젝트는 문제 정의 → 데이터 수집 → 데이터 전처리 → 유형·알고리즘 선정 → 모델 학습 → 성능 평가 및 수정 순서로 수행한다.
      테스트 사례는 학습에 쓰지 않고, 틀린 사례의 원인을 학습 데이터에서 찾아 고친 뒤 같은 테스트로 개선 전·후를 비교한다.
      성능 평가와 성찰은 「충분히」, 「괜찮았다」가 아니라 내 프로젝트의 이름과 숫자를 근거로 쓴다.
