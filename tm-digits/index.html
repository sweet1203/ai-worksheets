숫자 그리기: 학습 데이터 모으기

레이블마다 숫자를 그려서 넣어요

  1. 0 상자 아래의 ✏️ 그리기를 눌러요. "데이터를 그려주세요. 0" 그림판이 열려요.
  2. 마우스로 0을 크게 그리고 추가를 눌러요. 그림이 0 상자에 들어가요. 잘못 그렸으면 오른쪽 Erase(지우개)나 Reset(모두 지우기)을 써요.
  3. 0을 15장 그려요. 한 장 한 장 조금씩 다르게! 크게 · 작게 · 기울여서 · 둥글게 · 길쭉하게
  4. 1 상자에는 1을, 2 상자에는 2를 똑같이 15장씩 그려요. 상자 오른쪽 아래 동그라미 숫자가 그림 수예요. 세 상자가 비슷해야 해요.

학습시키기

버튼 하나로 딥러닝 학습이 시작돼요

  1. 왼쪽 위 < 프로젝트로 돌아가기를 누르고 학습 & 평가를 눌러요.
  2. 새로운 머신 러닝 모델을 훈련시켜보세요. 버튼을 눌러요.
  3. 학습이 끝날 때까지 기다려요. 보통 1~2분 걸려요. 화면에 "모델의 상태"가 표시돼요.
⚠️ 학습하는 동안 다른 탭으로 가지 마세요!브라우저 탭을 바꾸면 학습이 멈추거나 아주 느려질 수 있어요. 화면을 그대로 두고 기다려요.
💡 학습 버튼이 안 보이면?레이블마다 정해진 수 이상 그림이 있어야 학습할 수 있어요. 화면에 "적어도 ○개 이상의 데이터를 모아야 합니다"라고 나오면 그만큼 더 그려요.
🧠 딥러닝 개념과 연결버튼을 누르면 컴퓨터 안에서 순전파 → 오차 계산(손실 함수) → 역전파(경사 하강법)가 계속 반복돼요. 그림 전체를 여러 바퀴(에포크) 보면서, 몇 장씩 묶어(배치) 가중치를 고쳐요. 우리가 수업에서 배운 그 과정이 지금 실제로 일어나고 있어요!
5

테스트하기: 처음 보는 숫자로 시험

학습에 넣지 않은 새 그림으로 시험해요

  1. 학습이 끝나면 같은 화면 아래에 시험하는 버튼들이 나와요. 그림 그리기로 테스트하기를 눌러요.
  2. 훈련 때 넣지 않은 새 0을 그려서 시험해요. "○(으)로 인식되었습니다"라는 답과 확신도(%)가 나와요.
  3. 1과 2도 새로 그려서 시험해요.
  4. 맞힌 개수와 확신도를 아래 실험 기록표의 "기본 모델" 줄에 적어요.
테스트 결과 예시: 새로 그린 "2"를 넣었을 때
22(으)로 인식 · 확신도 87%

"이 그림은 2이고, 87% 확신한다"는 뜻이에요.

확신도는 어디서 나올까?

출력층 세 칸이 0, 1, 2에 확률을 나눠 주는데(합 100%), 그중 가장 큰 확률이 답과 확신도로 나와요.

🧠 딥러닝 개념과 연결훈련에 넣지 않은 새 그림 = 테스트 데이터예요. 공부할 때 본 문제가 아니라 처음 보는 문제로 시험해야 진짜 실력을 알 수 있어요. 확률을 합 100%로 나눠 주는 것이 소프트맥스이고, 확신도가 낮으면 인공지능이 "헷갈려" 하는 거예요.
6

실험 ①: 데이터가 적으면?

공부 자료가 5장뿐이면 어떻게 될까요?

  1. 예상하기: 레이블마다 그림이 5장뿐이면 결과가 어떻게 될지 먼저 기록표에 적어요.
  2. 위쪽 메뉴 프로젝트로 가서 새 프로젝트 숫자5장(인식 이미지)을 만들고, 레이블 0 · 1 · 2에 5장씩만 그려요.
  3. 학습시키고, 5단계와 같은 모양의 숫자를 그려 시험해요. 확신도가 어떻게 달라졌는지 기록해요.
  4. 15장으로 학습한 첫 프로젝트와 비교해요.
데이터 양과 정확도의 관계 (보통 이런 모양이에요)
🧠 딥러닝 개념과 연결공부 자료가 적으면 모양이 조금만 달라도 헷갈려요. 딥러닝은 데이터가 많을수록 더 잘 배워요. 그래서 다음 시간 파이썬 실습의 MNIST는 6만 장으로 학습해요.

실험 ②: 헷갈리는 숫자 7 추가

1과 7을 인공지능이 구분할 수 있을까요?

  1. 첫 프로젝트(손글씨숫자)의 훈련에서 7 레이블을 만들어요.
  2. 7을 15장 그려요. 몇 장은 1과 비슷하게(윗부분을 짧게, 길쭉하게) 그려 봐요.
  3. 학습 & 평가에서 다시 학습시키고, 새로 그린 1과 7로 시험해요.
  4. 확신도가 낮게 나오거나 틀린 경우를 기록하고, 왜 헷갈렸을지 생각해 적어요.

실험 ③ (도전): 낯선 그림으로 시험하기

내 그림으로만 공부한 인공지능은 낯선 그림도 알아볼까요?

  1. 그림 그리기로 테스트하기에서 평소와 다르게 그려 시험해요. ① 칸의 구석에 아주 작게 ② 아주 가늘고 길게 ③ 옆 친구가 내 컴퓨터에서 자기 스타일대로
  2. 결과를 기록해요. 어떤 그림을 잘 못 맞혔나요?
  3. 잘 못 맞힌 종류의 그림을 훈련에서 몇 장 더 그려 넣고 다시 학습시켜 봐요. 좋아졌나요?
🧠 딥러닝 개념과 연결공부한 문제는 잘 푸는데 처음 보는 문제를 못 풀면 과대적합이에요. 해결 방법은 다양한 데이터를 더 모으는 것! MNIST는 학생과 직원 수백 명의 글씨를 모았고, 모든 숫자를 크기를 맞춰 가운데에 놓아 두었어요. 구석에 작게 그린 숫자를 잘 못 맞혔다면 그 이유를 알 수 있겠죠?
