카메라로 가르치는
손글씨 숫자 인공지능

코드 없이, 내가 쓴 숫자 사진으로 딥러닝 모델을 직접 학습시켜 봐요. 구글 티처블 머신(Teachable Machine)을 사용해요.

012

🎯 오늘의 목표

① 직접 학습시키기

내가 쓴 0, 1, 2를 카메라로 보여 주고 인공지능을 학습시켜요.

② 실험해 보기

에포크를 바꾸고, 헷갈리는 숫자를 넣어 보며 결과가 어떻게 달라지는지 관찰해요.

③ 개념과 연결하기

오늘 한 일이 데이터 · 레이블 · 학습 · 에포크 · 소프트맥스 중 무엇인지 말할 수 있어요.

🎒 준비물

💻 웹캠이 있는 컴퓨터

크롬 브라우저 추천. 웹캠이 없으면 휴대폰으로 찍어 업로드해도 돼요.

📄 흰 종이 (A4 1~2장)

손바닥 크기로 잘라서 숫자 카드를 만들어요.

🖊️ 굵은 검정 사인펜

얇은 볼펜은 카메라에 잘 안 보여요. 굵을수록 좋아요.

💡 각 단계를 마치면단계 아래의 ✔ 다 했어요 버튼을 눌러요. 위쪽 동그라미가 초록색으로 바뀌어요.
1

손글씨 숫자 카드 만들기

인공지능에게 보여 줄 "공부 자료(데이터)"를 만들어요

  1. 종이를 손바닥 크기로 잘라 카드를 12장 만들어요.
  2. 학습용 카드 9장: 0, 1, 2를 3장씩 써요. 한 장 한 장 조금씩 다르게 써 보세요. (크게, 작게, 기울여서, 동그랗게…)
  3. 테스트용 카드 3장: 0, 1, 2를 1장씩 더 써서 뒤집어 숨겨 둬요. 학습이 끝난 뒤 인공지능이 처음 보는 숫자로 시험할 거예요.
  4. 모둠 친구와 카드를 몇 장 바꿔요. 다른 사람의 글씨가 섞이면 인공지능이 더 똑똑해져요.

  2. 시작하기 (Get Started) 버튼을 눌러요.
  3. 이미지 프로젝트 (Image Project)를 고르고, 표준 이미지 모델 (Standard image model)을 눌러요.

클래스 만들기: 0, 1, 2

인공지능이 구분할 "답의 종류"를 정해요

  1. Class 1 옆의 연필 ✏️ 을 눌러 이름을 0으로 바꿔요.
  2. Class 2의 이름을 1로 바꿔요.
  3. 아래쪽 ⊕ 클래스 추가를 눌러 새 클래스를 만들고 이름을 2로 바꿔요.

4

데이터 모으기: 카메라로 찍기

숫자마다 사진을 50장 이상 모아요

  1. 0 클래스의 📷 웹캠을 눌러요. 카메라 권한을 물으면 허용을 눌러요.
  2. 학습용 0 카드를 카메라 앞에 들고, 길게 눌러서 녹화하기 버튼을 꾹 누르고 있어요. 누르는 동안 사진이 계속 찍혀요.
  3. 찍는 동안 카드를 조금씩 움직여요. 가까이 · 멀리 · 살짝 기울이기 · 다른 0 카드로 바꾸기!
  4. 사진이 50장 이상 모이면 손을 떼요. (클래스 카드에 "이미지 샘플 ○○개"로 표시돼요)
  5. 1과 2 클래스도 똑같이 해요. 세 클래스의 사진 수가 비슷하게 되도록 해요.
👍 잘 찍는 방법숫자가 화면 가운데에, 화면을 꽉 채우게. 손가락이 숫자를 가리지 않게 카드 모서리를 잡아요. 밝은 곳에서 찍어요.
🚫 이렇게 하면 안 돼요얼굴이 크게 나오게 찍지 않아요. 숫자 없이 빈 화면만 찍히지 않게 해요. 테스트용 카드는 절대 찍지 않아요!
🧠 딥러닝 개념과 연결지금 모은 사진이 학습 데이터예요. 다양하게 찍을수록 처음 보는 숫자도 잘 맞혀요. 클래스마다 사진 수가 비슷해야 하는 이유는, 한쪽만 많으면 인공지능이 그쪽으로 치우쳐서(편향) 답하기 때문이에요.
5

학습시키기

버튼 하나로 딥러닝 학습이 시작돼요

  1. 가운데 학습 칸의 고급 ⌄을 눌러 펼쳐요. 아래 세 가지 숫자가 보여요. 지금은 바꾸지 말고 그대로 두세요.
  2. 모델 학습시키기 (Train Model)를 눌러요.
  3. 학습이 끝날 때까지 기다려요. 보통 30초~1분 걸려요.
고급 설정에 보이는 것기본값뜻 (딥러닝 수업에서 배운 개념)
에포크 (Epochs)50모은 사진 전체를 50바퀴 보며 공부해요. 단어장을 50번 복습하는 것과 같아요.
배치 크기 (Batch Size)16사진 16장씩 보고 가중치를 한 번 고쳐요. 단어 16개씩 외우고 쪽지시험 보는 것과 같아요.
학습률 (Learning Rate)0.001한 번에 가중치를 얼마나 크게 고칠지예요. 언덕을 내려가는 걸음 크기예요.
⚠️ 학습하는 동안 다른 탭으로 가지 마세요!브라우저 탭을 바꾸면 학습이 멈추거나 아주 느려져요. 화면을 그대로 두고 기다려요.
🧠 딥러닝 개념과 연결버튼을 누르면 컴퓨터 안에서 순전파 → 오차 계산(손실 함수) → 역전파(경사 하강법)가 계속 반복돼요. 우리가 수업에서 배운 그 과정이 지금 실제로 일어나고 있어요!
6

테스트하기: 처음 보는 숫자로 시험

숨겨 둔 테스트 카드를 꺼내요

  1. 학습이 끝나면 오른쪽 미리보기에 카메라 화면과 막대그래프가 나와요.
  2. 숨겨 둔 테스트 카드 0, 1, 2를 하나씩 카메라에 보여 줘요.
  3. 막대그래프의 퍼센트(%)를 읽고, 아래 실험 기록표의 "기본 모델" 줄에 맞힌 개수를 적어요.
미리보기 막대그래프 예시: 테스트 카드 "2"를 보여 줬을 때
04%
19%
287%

이 그래프를 읽으면?

"이 숫자가 2일 가능성이 87%"라는 뜻이에요. 가장 높은 막대가 인공지능의 답이에요. 세 막대를 더하면 항상 100%예요.

🧠 딥러닝 개념과 연결세 칸의 합이 100%가 되게 나눠 주는 것이 바로 소프트맥스 활성화 함수예요. 퍼센트가 낮게 나왔다면 인공지능이 "헷갈려" 하는 거예요.
7

실험 ①: 에포크를 바꾸면?

공부를 적게 시키면 어떻게 될까요?

  1. 예상하기: 에포크를 50에서 2로 줄이면 결과가 어떻게 될지 먼저 기록표에 적어요.
  2. 고급 ⌄에서 에포크를 2로 바꾸고 모델 학습시키기를 다시 눌러요.
  3. 테스트 카드 3장으로 다시 시험하고, 막대의 퍼센트가 어떻게 달라졌는지 기록해요.
  4. 고급 아래의 세부정보 보기 (Under the hood)를 눌러 에포크별 정확도·손실 그래프를 확인해요.
  5. 확인이 끝나면 에포크를 다시 50으로 바꾸고 학습시켜요.
세부정보 보기의 "에포크별 손실" 그래프는 보통 이런 모양이에요
🧠 딥러닝 개념과 연결에포크가 너무 적으면 공부가 덜 돼서 손실이 아직 큰 상태로 끝나요. 그래프에서 에포크가 늘수록 손실이 줄어드는 모습이 바로 경사 하강법으로 언덕을 내려가는 과정이에요.
8

실험 ②: 헷갈리는 숫자 7 추가

1과 7을 인공지능이 구분할 수 있을까요?

  1. 새 종이에 7을 3장 써요. 그중 하나는 1과 비슷하게 가늘고 길게 써 봐요. 테스트용 7 카드도 1장 더 만들어요.
  2. ⊕ 클래스 추가로 7 클래스를 만들고, 4단계처럼 사진을 50장 이상 찍어요.
  3. 다시 학습시키고, 테스트 카드 1과 7을 보여 줘요.
  4. 퍼센트가 낮게 나오거나 틀린 경우를 기록하고, 왜 헷갈렸을지 생각해 적어요.

🧠 딥러닝 개념과 연결클래스가 4개가 되면 출력층도 4칸이 돼요. 모양이 비슷한 숫자는 사람도 헷갈리죠? 인공지능도 비슷한 데이터끼리는 확률이 나뉘어요. 이럴 때는 더 다양하고 많은 데이터가 필요해요. 그래서 MNIST는 6만 장이나 모았어요.

실험 ③ (도전): 낯선 글씨로 시험하기

내 글씨로만 공부한 인공지능은 친구 글씨도 알아볼까요?

  1. 모둠 친구에게 0, 1, 2를 자기 스타일대로 새로 써 달라고 해요. 빨간 펜이나 아주 작은 글씨도 하나씩 써 봐요.
  2. 이 낯선 카드들을 내 모델에 보여 주고 결과를 기록해요.
  3. 잘 못 맞힌 카드가 있다면, 그런 카드를 학습 데이터에 추가로 찍고 다시 학습시켜 봐요. 좋아졌나요?
🧠 딥러닝 개념과 연결공부한 문제는 잘 푸는데 처음 보는 문제를 못 풀면 과대적합이에요. 해결 방법은 다양한 데이터를 더 모으는 것! MNIST가 학생과 직원 수백 명의 글씨를 모은 이유예요.
