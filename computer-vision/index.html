컴퓨터는
무엇을 '보고' 있을까?

사람 눈에는 고양이 사진이지만, 컴퓨터 눈에는 숫자로 가득 찬 표예요. 그 숫자 표에서 고양이를 찾아내는 기술, 컴퓨터 비전을 배워 봅니다.

오늘 우리는

컴퓨터가 사진을 어떤 숫자로 저장하는지부터 시작해서, 그 숫자 속에서 선 → 눈·코 → 얼굴 순서로 특징을 찾아내는 합성곱 신경망(CNN)의 원리를 배웁니다. 마지막에는 그림을 새로 만들어 내는 생성형 인공지능과, 우리 주변에서 컴퓨터 비전이 쓰이는 곳을 살펴봅니다.

왜 배울까
  • 사람은 바깥 정보의 대부분을 눈으로 받아들여요. 그래서 '보는 인공지능'은 자율 주행, 의료 영상, 보안처럼 사람의 눈을 대신하는 곳에 가장 먼저 쓰입니다.
  • 사진 앱이 인물을 알아서 묶어 주고, 번호판을 읽어 주차비를 계산하는 일이 어떻게 가능한지 설명할 수 있게 됩니다.
  • 지난 시간에 배운 신경망(가중치·활성화 함수·학습)이 이미지에 맞게 어떻게 바뀌는지 알게 되고, 이미지 분류 프로젝트의 바탕이 됩니다.
어디에 쓰일까
  • 글자 읽기 · 주차장 번호판 인식, 메뉴판을 읽어 소리로 들려주는 시각 보조 앱
  • 물건 찾기 · 도로 CCTV 교통량 분석, 공항 엑스레이 검색대
  • 얼굴 알아보기 · 휴대폰 얼굴 잠금 해제, 거리 사진 속 행인 얼굴 모자이크
  • 새로 만들기 · 글로 설명하면 그림을 그려 주는 생성형 인공지능
배우고 나면 할 수 있는 것
  • 픽셀값과 RGB 값을 보고 어떤 색인지 말한다.
  • 이미지 분류·객체 위치 식별·객체 탐지·이미지 분할을 구분한다.
  • 합성곱 연산을 손으로 계산하고, 최댓값 풀링 결과를 구한다.
  • CNN이 이미지를 분류하는 과정을 합성곱층 → 풀링층 → 완전 연결층으로 설명한다.
  • GAN의 생성자와 감별자가 어떻게 경쟁하며 학습하는지 설명한다.
  • 컴퓨터 비전 서비스를 직접 써 보고 어느 분야 기술인지 말한다.

03

왜 합성곱 신경망일까

사진을 그냥 신경망에 넣으면 생기는 두 가지 문제

👶 개와 고양이, 어떻게 구별했어요?

그림 카드로 개와 고양이를 배운 아이는 길에서 처음 보는 개와 고양이도 금방 알아봐요. 그런데 "무엇을 보고 알았어?"라고 물으면 제대로 설명하지 못해요. 어른에게도 어려운 질문이죠.

이렇게 사람이 특징을 말로 정해 주기 어려운 문제는, 사람이 특징을 뽑아 주는 기존 기계학습보다 스스로 특징을 찾는 딥러닝이 더 잘해요. 그중 이미지 분류를 가장 잘하는 모델이 합성곱 신경망(CNN, Convolutional Neural Network)이에요.

문제 ① 가중치가 너무 많아진다

지난 시간처럼 이미지를 한 줄로 펴서 완전 연결층(은닉층 뉴런 100개)에 넣으면, 픽셀 하나마다 뉴런 100개와 연결선이 생겨요.

CNN의 필터는 3×3 크기라면 가중치가 9개뿐이에요. 이 9개를 이미지 전체에 돌려 가며 함께 써요(공유). 이미지가 커져도 필터의 가중치 수는 그대로예요.

문제 ② 위아래 이웃이 멀어진다

세로선 하나를 그린 6 × 6 그림이에요. 한 줄로 펴면 위아래로 붙어 있던 점들이 어떻게 될까요?

세로선의 점 6개가 6칸씩 떨어진 곳으로 흩어져요. 한 줄로 펴면 이미지의 2차원(가로·세로) 모양 정보가 무시돼요. CNN은 펴지 않고 2차원 그대로 이웃한 픽셀끼리 살펴봐요.

CNN은 이렇게 생겼어요

합성곱층과 풀링층을 여러 번 거치며 특징을 뽑고(특징 추출), 마지막 완전 연결층이 무엇인지 분류해요.

층마다 찾는 특징이 달라요. 아래 카드를 눌러 보세요.

합성곱층과 필터

작은 돋보기가 이미지 위를 한 칸씩 지나가며 특징을 찾는다

① 합성곱 연산: 같은 자리끼리 곱하고, 모두 더하기

필터(커널)는 작은 가중치 묶음이에요. 이미지의 왼쪽 위에서 시작해 한 칸씩 오른쪽·아래로 움직이며, 겹친 칸끼리 곱해서 모두 더한 값을 출력에 적어요. 오른쪽 아래에 도착할 때까지 반복해요.

② 필터를 바꾸면 찾는 특징이 바뀐다

맨 왼쪽 칸에 마우스나 손가락으로 그림을 그려 보세요. 필터 A는 세로 방향 경계선을, 필터 B는 가로 방향 경계선을 찾아요. 밝게 빛나는 곳이 필터가 "찾았다!" 하고 반응한 곳이에요.

결과가 원본보다 조금 작죠? 3 × 3 필터는 가장자리 밖으로 나갈 수 없어서, 28 × 28 이미지가 26 × 26이 돼요. (위의 4 × 4 → 2 × 2와 같은 이유예요.)

교과서 104쪽 · 그림 Ⅱ-21 이미지에 필터를 적용하여 특징을 추출한 예
Q. 필터 숫자는 누가 정해요?사람이 정하지 않아요. 처음에는 아무 숫자로 시작해서, 훈련 데이터를 넣고 틀린 만큼 고치는 학습을 하며 특징을 잘 찾는 필터로 바뀌어 가요. 지난 시간에 가중치를 고치던 것과 같아요. 필터의 숫자가 바로 가중치니까요.
Q. 필터는 하나만 써요?아니요. 필터마다 찾는 특징이 달라서 한 층에 여러 개의 필터를 함께 써요. 그래서 한 이미지에서 세로선, 가로선, 곡선 같은 여러 특징 지도가 동시에 나와요.

풀링층과 완전 연결층

줄여서 핵심만 남기고, 마지막에 이름을 붙인다

① 풀링층: 구역마다 대표 하나만

합성곱층을 지난 데이터를 작은 구역(2 × 2)으로 나누고, 구역마다 가장 큰 값 하나만 남겨요(최댓값 풀링). 가장 큰 값은 필터가 가장 강하게 반응한 곳, 즉 가장 중요한 특징이에요.

06

생성형 인공지능과 GAN

알아보는 인공지능에서, 새로 만들어 내는 인공지능으로

생성형 인공지능은 텍스트, 오디오, 이미지 같은 기존 콘텐츠로 배운 것을 바탕으로 비슷한 콘텐츠를 새롭게 만들어 내는 인공지능이에요. 대표 알고리즘이 생성적 적대 신경망(GAN)이에요. 이름의 '적대'는 두 모델이 서로 경쟁한다는 뜻이에요.

🎨 생성자 (generator)가짜 데이터를 만드는 쪽. 위조지폐를 만드는 사람처럼, 진짜와 똑같아 보이는 가짜를 만들려고 애써요.
🔍 감별자 (discriminator)진짜인지 가짜인지 가려내는 쪽. 위조지폐를 잡아내는 경찰처럼, 가짜를 골라내려고 애써요.

⚔️ GAN 경쟁 지켜보기

생성자의 목표는 오른쪽 '진짜 그림'과 구별되지 않는 그림을 만드는 거예요. 「한 번 겨루기」를 여러 번 눌러 보세요.

  1. ① 생성자가 가짜 데이터를 만든다
  2. ② 감별자가 진짜와 가짜 중 진짜를 골라낸다
  3. ③ 감별자가 분류 결과로 학습해 더 잘 가려낸다
  4. ④ 생성자가 감별 결과로 학습해 더 그럴듯하게 만든다
감별자: 아직 겨루기 전이에요.
감별자가 가짜를 맞힌 비율 -
학습 끝! 감별자가 가짜를 맞힌 비율이 50% 가까이 내려갔어요. 동전 던지기로 찍는 것과 같아졌다는 뜻이에요. 감별자가 더 이상 진짜와 가짜를 구분하지 못하면 학습을 멈추고, 이렇게 학습된 생성자를 새로운 데이터를 만드는 데 써요.

실제 GAN은 수천 번 넘게 겨루며 학습해요. 여기서는 흐름이 잘 보이도록 줄여서 보여 줘요.

컴퓨터 비전의 주요 분야는 이미지 분류, 객체 위치 식별, 객체 탐지, 이미지 분할이다.
합성곱 신경망은 이미지 분류를 잘하며 합성곱층, 풀링층, 완전 연결층으로 이루어진다.
생성형 인공지능은 배운 내용을 바탕으로 기존 콘텐츠와 비슷한 콘텐츠를 새롭게 만든다.
픽셀 · RGB흑백 픽셀 = 0(검정)~255(흰색) 숫자 1개, 컬러 픽셀 = (R, G, B) 숫자 3개🟨 (255, 255, 0) = 노랑
4대 분야분류 → 위치 식별 → 탐지 → 분할. 단일 → 다중 객체, 사각형 → 픽셀 단위🐱 Cat → Cat + 위치 → Dog, Dog, Cat
