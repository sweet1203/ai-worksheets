오늘 우리는

3단원에서 만난 사례 하나를 골라 내 입장을 정리하고, 인공지능을 만드는 사람으로서 지킬 약속을 정합니다. 그리고 4단원에서 직접 만들 인공지능 프로젝트를 주제 · 데이터 · 만들 것 세 가지로 나누어 살펴보고, 내 프로젝트 계획 한 장을 채웁니다.

왜 할까
  • 지금까지는 인공지능을 쓰는 사람의 눈으로 봤다면, 이제는 만드는 사람이 돼요.
  • 무엇을 만들지 미리 그려 두면, 직접 만들 때 헤매지 않고 내 주제에 집중할 수 있어요.
3단원 핵심 질문
  • 인공지능의 발전은 우리에게 어떤 변화를 가져올까?
  • 인공지능 사회의 구성원으로서 갖추어야 할 윤리 의식은 무엇일까?
배우고 나면 할 수 있는 것
  • 3단원 사례에 대한 내 입장을 까닭과 함께 말한다.
  • 좋은 프로젝트 주제와 피해야 할 주제를 구분한다.
  • 데이터 유형에 맞게 데이터를 모으는 방법과 주의할 점을 말한다.

02

무엇을 만들까

프로젝트를 마치면 내 손에 남는 것 세 가지

쉽게 말하면오늘은 만드는 방법보다 다 만들었을 때의 모습을 먼저 봐요. 내가 정한 문제를 푸는 인공지능 모델을 만들고, 그 결과로 움직이는 Scratch 프로그램을 만들고, 그 과정을 기록해요. 도구를 쓰는 방법은 따로 연습하는 시간이 있어요.
🧠

ML4Kids 모델

03

주제 정하기

인공지능이 무엇을 보고(입력) 무엇으로 나눌지(출력) 정하기

쉽게 말하면주제는 「무엇을 넣으면 어느 칸으로 나눠 주는 인공지능」인지 정하는 일이에요. 좋은 주제는 내가 수업 시간에 데이터를 직접 모을 수 있고, 결과가 2~3개의 칸으로 분명하게 나뉘어요.

✅ 좋은 주제의 네 가지 조건

🗂️

칸이 2~3개로 나뉜다

클래스가 2개 이상이고, 칸끼리 겹치지 않아요.

예: 긍정 / 부정
✋

직접 모을 수 있다

교실이나 집에서 내가 찍고, 녹음하고, 쓸 수 있는 데이터예요.

예: 필통·물병 사진, 손뼉 소리
👀

사람도 구분할 수 있다

사람이 봐도 정답을 정할 수 없으면 인공지능도 배울 수 없어요. 칸을 나누는 기준이 분명해야 해요.

🤝

쓰임이 있다

누구에게 어떤 도움이 되는지, 틀리면 누가 곤란한지 말할 수 있어요.

3단원에서 배운 내용과 이어져요

🚫 피해야 할 주제

이런 주제는왜 피할까
클래스가 하나뿐이거나, 답이 너무 뻔한 주제 (빨간 종이 / 파란 종이처럼 틀릴 일이 거의 없는 것)틀린 사례를 찾아 원인을 알아보고 고치는 과정을 할 수 없어요.
사람의 얼굴, 이름, 학번, 목소리로 누구인지 맞히는 주제다른 사람의 개인정보를 모으게 돼요.
인터넷에서 연예인·캐릭터 사진이나 남이 쓴 글을 모아야 하는 주제저작권과 초상권을 지키기 어려워요.
사람을 외모·성별·사는 곳 등으로 나누거나, 폭력·혐오와 관련된 주제3단원에서 배운 편향과 차별을 내가 만들게 돼요.
수업 시간에 모을 수 없는 데이터가 필요한 주제 (몇 년 치 주가, 병원 진료 기록 등)데이터를 직접 모으고 확인할 수 없어요.

04

데이터 모으기

몇 개를, 어떻게 모으고, 무엇을 조심할까

쉽게 말하면인공지능은 내가 넣어 준 데이터만큼만 배워요. 데이터가 적거나 한쪽으로 치우치면, 3단원에서 본 표정 알아보기 인공지능처럼 특정 상황에서만 계속 틀리는 인공지능이 돼요.

📌 모든 유형에 공통인 약속

📏

8개 이상, 비슷하게

클래스마다 8개 이상 모으고, 클래스끼리 개수를 비슷하게 맞춰요.

✋

직접 모은 데이터

유형 카드의 시작 예시를 쓰면 클래스마다 3개 이상 직접 더하고, 둘을 나눠 기록해요. 이미지·소리는 모두 직접 찍고 녹음해요.

🧪

테스트 4개는 따로

테스트할 사례 4개 이상은 처음부터 떼어 두고 학습에 넣지 않아요.

🗂️

어디서 몇 개

클래스마다 몇 개를, 어디서 어떻게 모았는지 적어 둬요.

🧭 데이터 유형별로 모으는 법

🔒 저작권과 개인정보 지키기

⭕

써도 돼요

내가 직접 쓴 문장, 직접 잰 숫자

⚠️

조심해서 써요

친구의 목소리·손 사진: 먼저 허락을 받고, 얼굴과 이름이 나오지 않게 해요.

인터넷의 사진·글: 되도록 쓰지 않아요. 꼭 써야 하면 누구나 써도 된다고 표시된 것인지 확인하고 출처를 적어요.

생성형 AI가 알려 준 아이디어: 참고만 하고, 실제 데이터는 내가 고르고 확인해요. 썼다면 어디에 어떻게 썼는지 기록해요.
