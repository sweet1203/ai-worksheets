02

지속가능발전목표(SDGs)

교과서 171쪽 · 지속 가능 발전을 위한 인류 공동의 약속

쉽게 말하면지속 가능 발전은 지금 우리도 잘 살고, 미래 세대도 계속 잘 살 수 있게 사회·경제·환경을 함께 챙기는 발전이에요. 이를 위해 세계가 2015년에 「2030년까지 이것만은 해내자」고 정한 17가지 목표가 SDGs예요.
🌐

SDGs란?

Sustainable Development Goals. 2015년 유엔(UN)이 2030년까지 달성하기로 한 인류 공동의 목표예요.

🤝

단 한 사람도 소외되지 않게

슬로건은 「Leave no one behind」. 사람·지구 환경·번영·평화·파트너십 5개 영역, 17개 목표와 169개 세부 목표로 이루어져요.

🇰🇷

우리나라의 K-SDGs

유엔 SDGs를 우리 상황에 맞게 바꾼 국가 지속가능발전목표예요. 제4차 기본 계획(2021~2040)은 17개 목표를 유지하고 119개 세부 목표, 236개 지표를 제시해요.

🧩 17개 목표를 눌러 보세요 (국가 지속가능발전목표 K-SDGs 표기)

목표를 하나 누르면 내용과 인공지능 활용 아이디어가 나와요.

04

인공지능 문제 해결 5단계

교과서 174~175쪽 · 2단원의 기계학습 과정을 프로젝트에 맞게

쉽게 말하면2단원에서 배운 기계학습 과정과 같아요. 무엇을 풀지 정하고 → 데이터를 모아 다듬고 → 방법을 고르고 → 학습시키고 → 평가해서 고친다. 아래 초록 칸은 이 단계가 ML4Kids 수행평가에서는 무엇인지예요.
1

문제 정의

인공지능으로 풀 수 있는 문제인지, SDGs와 관련 있는지 살피고 목표를 구체적이고 측정할 수 있게 정해요. 분류 문제인지 회귀(예측) 문제인지도 구분해요.

ML4Kids: 문제 한 문장, 입력·출력, 클래스 정하기
2

데이터 수집 및 전처리

데이터 수집 → 분석 → 전처리 → 분할. 데이터가 온전하지 않으면 모델이 잘못 배워요.

ML4Kids: 클래스별 예시 모으기, 개수 맞추기, 테스트 사례는 따로 빼 두기
3

유형과 알고리즘 선정

기계학습 유형(분류·예측·군집), 데이터 크기와 특성, 계산 복잡도와 훈련 시간을 고려해요. 여러 알고리즘을 비교하면 좋아요.

ML4Kids: 데이터 유형(텍스트·숫자·이미지·소리) 고르기 = 분류 문제
4

모델 학습

훈련 데이터로 학습시키고, 테스트 데이터로 성능을 평가해 적합한 모델을 만들어요.

ML4Kids: 「학습」 버튼으로 모델 만들기
5

성능 평가 및 수정

평가 지표 선택 → 성능 측정 → 개선 → 수정된 모델 재평가 → 모델 적용.

ML4Kids: 테스트 → 틀린 사례 → 데이터 고치기 → 같은 테스트로 다시 → Scratch 연결

핵심 문장 · 마무리 퀴즈 · 생각 정리 질문폼

지속가능발전목표(SDGs)는 2015년 유엔이 정한 2030년까지의 17개 목표로, 「단 한 사람도 소외되지 않는 것」을 내세운다.
인공지능 문제 해결은 문제 정의 → 데이터 수집 및 전처리 → 유형과 알고리즘 선정 → 모델 학습 → 성능 평가 및 수정의 5단계로 진행한다.
