오늘 우리는

실제 숫자로 사회 문제가 얼마나 심각한지 보고, 교과서 사례와 지금 실제로 쓰이는 인공지능이 그 문제에 어떻게 다가가는지 살펴봅니다. 마지막으로 내 관심사와 진로에서 출발해 내가 풀고 싶은 문제를 한 문장으로 적어 봅니다. 화면마다 있는 질문에는 정답이 없어요. 내 생각을 그대로 써요.

왜 할까
  • 인공지능 프로젝트는 기술보다 문제에서 시작해요. 누가 왜 힘든지 알아야 무엇을 만들지 정할 수 있어요.
  • 앞으로 어떤 일을 하든 내 분야의 문제를 데이터로 보는 눈이 필요해요.
학습 목표 (171쪽)

  • 인공지능과 관련된 사례를 찾을 수 있다.
오늘 남길 것
  • 가장 마음이 쓰이는 사회 문제와 그 까닭

숫자로 보는 지금 우리 사회의 문제

쉽게 말하면인공지능 이야기보다 문제가 먼저예요. 뉴스로 스쳐 지나간 문제도 숫자로 보면 크기가 보이고, 누가 가장 힘든지도 보여요. 카드를 천천히 읽어 보세요.

숫자는 발표 기관과 시점에 따라 조금씩 달라요. 카드 아래에 출처와 시점을 적어 두었어요.

02

세계가 함께 정한 목표 · SDGs

교과서 171쪽 · 지속 가능 발전을 위한 인류 공동의 약속

쉽게 말하면앞에서 본 문제들은 우리나라만의 문제가 아니에요. 세계는 2015년에 「지금 우리도, 미래 세대도 계속 잘 살 수 있게 2030년까지 이것만은 해내자」며 17가지 목표를 정했어요. 이것이 지속가능발전목표(SDGs)예요.
🌐

SDGs란?

Sustainable Development Goals. 2015년 유엔(UN)이 2030년까지 달성하기로 한 인류 공동의 목표예요.

🤝

단 한 사람도 소외되지 않게

슬로건은 「Leave no one behind」. 사람·지구 환경·번영·평화·파트너십 5개 영역, 17개 목표와 169개 세부 목표로 이루어져요.

🇰🇷

우리나라의 K-SDGs

유엔 SDGs를 우리 상황에 맞게 바꾼 국가 지속가능발전목표예요. 제4차 기본 계획(2021~2040)은 17개 목표를 유지하고 119개 세부 목표, 236개 지표를 제시해요.

🔗 앞에서 본 문제는 어느 목표와 이어질까

한 문제가 여러 목표와 이어지기도 해요. 내 생각과 다르면 그 까닭을 생각해 봐요.

🧩 17개 목표를 눌러 보세요 (국가 지속가능발전목표 K-SDGs 표기)

목표를 하나 누르면 내용과 인공지능 활용 아이디어가 나와요.

03

데이터와 인공지능은 어떻게 다가갈까

교과서 172~173쪽 AI for Good · 그리고 지금 실제로 쓰이는 인공지능

쉽게 말하면인공지능이 문제를 혼자 「해결」하지는 않아요. 사람이 다 볼 수 없던 것을 대신 보고 듣고, 일이 커지기 전에 미리 알려 주면, 사람이 더 빨리 움직여 문제를 풀어요. 사례마다 어떤 데이터로 → 무엇을 알아내고 → 사람은 무엇을 하는지 보세요.
👀

대신 보고 듣기

사진·영상·소리 속에서 연기, 전기톱 소리, 병든 잎을 찾아 분류·탐지해요.

🔮

미리 알기

쌓인 데이터의 패턴으로 수확량, 에너지 사용량, 위험이 커질 곳을 예측해요.

📞

빠짐없이 살피기

사람이 매일 할 수 없는 일을 24시간, 수만 곳에서 반복해서 지켜봐요.

🎯

먼저 도울 곳 찾기

도움이 급한 사람, 먼저 가 봐야 할 곳을 골라 사람의 손이 먼저 닿게 해요.

🔍 함께 보면 좋은 점 · 📰 농작물 병해충 사진 진단은 사진을 넣으면 어느 칸인지 알려 주는 이미지 분류예요. 우리가 ML4Kids로 만들 모델과 같은 방식이에요.

04

한 사례로 따라가 보기 · 인공지능 문제 해결 5단계

교과서 174~175쪽 · 산불 연기를 알아보는 인공지능을 만든다면

쉽게 말하면인공지능으로 문제를 푸는 과정은 5단계예요. 무엇을 풀지 정하고 → 데이터를 모아 다듬고 → 방법을 고르고 → 학습시키고 → 평가해서 고쳐요. 앞에서 본 산불 감시 카메라를 우리가 만든다고 생각하며 따라가 봐요. 아래 초록 칸은 우리가 ML4Kids로 할 때의 모습이에요.
1

문제 정의

「어떻게 하면 산불 연기를 더 빨리 알아챌 수 있을까?」 카메라 사진을 넣으면 연기 있음 / 연기 없음을 알려 주는 분류 문제로 정해요. 목표는 구체적이고 측정할 수 있게: 「연기를 몇 장 중 몇 장 찾나」.

ML4Kids: 문제 한 문장, 넣을 사진(입력)과 맞힐 것(출력), 클래스 정하기
2

데이터 수집 및 전처리

연기 사진만 모으면 안 돼요. 연기와 헷갈리는 구름·안개·먼지 사진, 낮과 저녁, 여러 계절 사진을 골고루 모아요. 흐린 사진은 빼고, 잘못 붙은 이름표는 고치고, 시험용 사진은 따로 떼어 둬요(수집 → 분석 → 전처리 → 분할).

ML4Kids: 클래스별 사진 찍기, 흐리거나 잘못 넣은 사진 정리, 장수 맞추기, 테스트 사진 따로 두기
3

유형과 알고리즘 선정

맞힐 것이 「종류」라서 분류, 데이터가 사진이라서 이미지 모델을 골라요. 데이터 크기와 특성, 계산에 드는 시간도 생각해요.

ML4Kids: 이미지 프로젝트 = 사진을 클래스로 나누는 분류
4

모델 학습

훈련용 사진으로 모델을 학습시켜요. 모델은 연기 사진들의 공통된 특징을 스스로 찾아요.

ML4Kids: 「학습」 버튼으로 모델 만들기
5

성능 평가 및 수정

떼어 둔 사진으로 시험해요. 연기를 놓친 사진과 구름을 연기라고 한 사진을 따로 세어 보고, 원인에 맞게 데이터를 더하거나 고쳐 다시 시험해요.

ML4Kids: 새 사진으로 테스트 → 정확도 → 틀린 사진의 원인 → 고칠 방향
📰 실제로는 · 산불 감시 카메라에 AI를 붙여 더 빨리 연기를 찾은 사례도 있지만, 전국 무인 감시 카메라가 처음 발견한 산불은 전체의 약 3%에 그쳤다는 보도도 있어요(2026년 3월). 카메라가 볼 수 없는 곳이 많고, 사람의 신고가 더 빠른 경우도 있기 때문이에요. 시험에서 잘 맞히는 모델과 현장에서 실제로 도움이 되는 모델은 다를 수 있어요.

07

마무리

오늘의 핵심 · 생각 정리 질문폼

사회 문제는 숫자로 보면 크기가, 사람으로 보면 무게가 보인다. 인공지능 프로젝트는 누가 왜 힘든지에서 시작한다.
데이터와 인공지능은 사람이 다 볼 수 없던 것을 대신 보고, 미리 알리고, 빠짐없이 살펴 사람이 더 빨리 움직이게 돕는다. 틀릴 수 있으니 한계와 사람의 몫을 함께 생각한다.
문제 해결은 문제 정의 → 데이터 수집 및 전처리 → 유형과 알고리즘 선정 → 모델 학습 → 성능 평가 및 수정으로 진행하고, 주제는 내 관심사와 진로에서 찾아 「어떻게 하면 ___ 할 수 있을까?」로 쓴다.
