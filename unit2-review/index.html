    내가 그린 숫자, 모델은 맞힐까?

    AI 역량 키우기 · 선택 활동 (교과서 121쪽 보충 · 심화)

    쉽게 말하면모델은 28 × 28 흑백 사진만 볼 줄 알아요. 그래서 내가 그린 그림을 흑백으로 바꾸고, 색을 뒤집고, 28 × 28로 줄이고, 숫자 784개로 펴고, 0~1로 나누는 전처리를 거쳐야 해요. 교과서 121쪽 심화 코드가 바로 이 일을 해요.

    ① 숫자를 그리고 두 모델에게 물어보기

    마우스나 손가락으로 0~9 숫자 하나를 크게 그려요.

    model 은닉층 2개 · 가중치 84,060개
    ?
    model2 은닉층 5개 · 가중치 224,760개
    ?

    여러 숫자를 그려 보며 기록해 봐요. 두 모델이 다르게 답한 숫자가 있나요? 모델이 자주 틀리는 숫자는 무엇인가요? 숫자를 아주 작게, 또는 한쪽 구석에 그리면 어떻게 되나요?

    ② 심화 코드가 하는 일 (교과서 121쪽)

    교과서 121쪽 심화 활동은 그림판으로 그린 숫자를 Colab에 올려 120쪽에서 만든 모델에 넣어요. 위 ①의 작은 그림 다섯 장이 바로 아래 코드 한 줄 한 줄이 하는 일이에요. 빈칸에 들어갈 말을 생각해 보세요.

    img = cv2.imread(file) # 이미지 불러오기 img = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) # 흑백으로 변환 → 그림 ② img = cv2.bitwise_not(img) # 반전 → 그림 ③ img = cv2.resize(img, dsize = (28, 28)) # 크기 조절 → 그림 ④ img_ary = np.array( ① ) # 이미지를 numpy로 변환 img_flatten = img_ary.reshape(1, 784) # 한 줄로 만들기 → 숫자 784개 img_scaler = img_flatten.astype( ② ) / 255 # 정규화 → 그림 ⑤ img_predict = np.argmax(model2.predict(img_scaler), axis = 1) # 분류 실행
    💡 빈칸 힌트

    ① 바로 위 줄까지 손질한 이미지가 담긴 변수 이름이에요. ② 255로 나누면 0~1 사이 소수가 되니, 정수가 아니라 실수 자료형으로 바꿔야 해요. 99쪽에서 MNIST를 정규화할 때 쓴 자료형과 같아요.

    수업 페이지는 MNIST처럼 숫자를 가운데로 옮기는 단계를 하나 더 해요. MNIST 손 글씨는 모두 숫자가 가운데에 오도록 맞춰져 있어서, 이렇게 해야 모델이 더 잘 맞혀요.

    2단원 마무리

    핵심 문장과 마무리 퀴즈

    기계학습은 데이터와 결괏값으로 규칙을 찾으며, 문제 정의 → 데이터 수집 → 전처리 → 유형·알고리즘 선정 → 모델 학습 → 성능 평가·수정 순서로 문제를 해결한다.
    딥러닝은 다중의 은닉층으로 구성된 인공신경망으로, 순전파 → 오차 계산 → 역전파를 반복하며 스스로 특징을 찾아 복잡한 문제를 해결한다.
    딥러닝은 컴퓨터 비전, 음성 인식, 자연어 처리에 활용되며, 은닉층을 늘린다고 성능이 항상 좋아지는 것은 아니다.
